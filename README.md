# Draw Signals

PWA για κινητό που αξιολογεί σήματα ισοπαλίας για La Liga, Serie A, Premier League, Ligue 1 και Super League 1.

## Πώς δουλεύει
- `scripts/update.mjs` κατεβάζει από το football-data.co.uk τα αποτελέσματα της σεζόν (`mmz4281/<σεζόν>/<κωδικός>.csv`) και το `fixtures.csv` (επόμενοι αγώνες με 1X2 και O/U 2.5), και γράφει το `public/data.json`.
- Το GitHub Actions (`.github/workflows/update.yml`) το τρέχει αυτόματα Τρίτη, Παρασκευή (δύο φορές), Σάββατο και Κυριακή, και δημοσιεύει το app στο GitHub Pages.
- Το app (`public/`) υπολογίζει τα σήματα στο κινητό με το `public/logic.js`, ώστε οι ρυθμίσεις κριτηρίων να ισχύουν αμέσως.
- Αν μια λήψη αποτύχει, κρατιούνται τα προηγούμενα δεδομένα με ένδειξη «παλιά». Τίποτα δεν εφευρίσκεται: ό,τι λείπει εμφανίζεται ως «εκκρεμεί» ή «άγνωστη / ουδέτερη τάση».

## Χειροκίνητα
- Στο app: κουμπί «↻ Ανανέωση».
- Νέα λήψη δεδομένων: GitHub → Actions → «Ενημέρωση δεδομένων & δημοσίευση» → Run workflow.
- Τοπικά: `npm run update` και `npm test`.

## Χρώματα
Όλα στο `public/theme.css` (φωτεινό και σκοτεινό θέμα).

## Εγκατάσταση στο κινητό
Άνοιξε το link του GitHub Pages. Σε Android/Chrome: μενού → «Προσθήκη στην αρχική οθόνη». Σε iPhone/Safari: Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».

## Ενεργοποίηση στο GitHub (μία φορά)
1. Ανέβασε τα αρχεία σε ένα δημόσιο repo (branch `main`).
2. Settings → Pages → Source: «GitHub Actions».
3. Actions → Run workflow για την πρώτη λήψη.
